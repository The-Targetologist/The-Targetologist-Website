# Design System

**Status: pending brand input.** Unlike the Mian Tayyab Steel project (which had a finalized brand guidelines document), this project does not yet have confirmed brand colors/typography. Do not invent a final palette — use a placeholder professional palette (e.g. a dark navy/charcoal primary + single accent color + white/light neutral) and clearly mark it as provisional pending real brand input, OR pull colors from the existing logo SVG (`Targetologist-Logo-Updated.svg`) if it has a clear color story.

## Typography (provisional — confirm before final)
- Headings: a confident sans-serif (e.g. Inter, Sora, or similar — avoid anything overly playful/rounded given the "no-nonsense" tone)
- Body: a clean, readable sans-serif, can match or pair with the heading font
- Do not finalize font choices as "done" in PROJECT_STATE.md until the business owner confirms

## Color roles (provisional)
- Primary — dominant brand color, used for headings/buttons/nav active states
- Accent — single supporting color for CTAs/highlights, used sparingly
- Neutral/background — white or light neutral background, dark text

## Spacing/grid
Standard 8px spacing scale, container max-width ~1280px, consistent section vertical padding (e.g. 96-128px desktop, 64px mobile) — avoid Lab41's density; this site has fewer sections and can afford more breathing room per section.
