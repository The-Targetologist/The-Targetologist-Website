# Wireframe Spec

## Home page section order
1. Header (logo, nav, Book a Strategy Call button)
2. Hero — headline + subhead + primary CTA
3. Problem framing — "Most businesses don't have a lead problem, they have a system problem" (real line from current site, can be tightened)
4. Services overview — 2 cards (Automation, Advertisement), each linking to its full service page
5. How it works — numbered process (reworded from Lab41's shape, our own steps/copy)
6. Who we work with — industry categories (no named clients without permission)
7. Why The Targetologist — differentiators, written honestly for a 2-service focused shop, not inflated to sound like a 6-service enterprise agency
8. Final CTA — Book a Strategy Call
9. Footer

## Service page (Automation / Advertisement) section order
1. Header
2. Hero — service name + one-line value prop
3. The problem this service solves
4. How we do it — process/method specific to this service
5. What's included (concrete deliverables, not vague promises)
6. Who this is for (industry fit)
7. FAQ (service-specific)
8. CTA — Book a Strategy Call
9. Footer

## About page section order
1. Header
2. Founder/team intro
3. Why this agency exists (the "system, not tactics" philosophy)
4. How we work (brief, links back to service pages for depth)
5. CTA
6. Footer

## Contact page
1. Header
2. Contact info block (phone, email, address)
3. Booking/contact form
4. CTA reinforcement
5. Footer

## Responsive notes
Mobile nav collapses to a hamburger menu; Book a Strategy Call button remains visible/accessible even when nav is collapsed (sticky or always-shown). Service cards stack vertically on mobile — 2 cards is a manageable stack, no carousel needed.
