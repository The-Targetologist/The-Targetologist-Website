# Design Direction

## Tone
Confident, direct, no-nonsense — matches the existing "No hacks. No random outreach." line from the current site. This is a B2B systems/operations agency, not a flashy creative shop. Avoid generic SaaS/startup visual clichés (see the same anti-pattern list used on the Mian Tayyab Steel project: gradient blobs, glassmorphism, floating cards, fake stat counters, generic icon grids).

## What to borrow from Lab41 (quality signals only)
- Clean, high-contrast typography-led hero
- Numbered process section with clear visual hierarchy
- Restrained, confident color usage (not overly colorful)
- Clear visual separation between sections without heavy dividers/gradients

## What NOT to borrow
- Their specific color palette (until we define our own)
- Their stat-heavy trust bar treatment (we don't have Lab41-scale numbers to show — see `02-reference-site-audit.md`)
- Their 6-card service grid density — our grid should reflect 2 services, styled to feel complete, not stretched or padded

## Open decisions requiring input before finalizing
- Primary/secondary brand colors — does The Targetologist have existing brand colors from the current WordPress site/logo (a navy-and-accent scheme is common for "systems/ops" positioning, but confirm against the actual logo before assuming)
- Typography — confirm if there's an existing brand font pairing, or if this project should establish one fresh
- Logo — reuse the existing SVG logo from the WordPress site (`Targetologist-Logo-Updated.svg`) unless a new one is planned

## Imagery direction
Real photography of the actual team/founder where available and consented; otherwise clean, professional stock imagery (dashboards, CRM/automation visuals, operations-themed) — avoid overly staged "handshake" stock photo clichés.
